# ミディカルチャー（Midi Culture）


## ■ ミディカルチャーとは

プラスミドDNAを多く回収するために、大腸菌を中容量で培養する操作である。

## ■ 使用するもの

- Tryptone
- Yeast Extract
- NaCl
- ddH₂O
- AmpicillinまたはKanamycin（いずれもstock 100 mg/mL）
- 三角フラスコ、アルミホイル、オートクレーブ
- Mini Cultureの残りの大腸菌培養液

## ■ 手順

**1.** 以下を三角フラスコに入れ、LB液体培地を作製する。

| 試薬 | 使用量 |
|---|---:|
| Tryptone | 1 g |
| Yeast Extract | 0.5 g |
| NaCl | 0.5 g |
| ddH₂O | 100 mL |

**2.** フラスコの口をアルミホイルで覆い、オートクレーブ滅菌する。

**3.** 滅菌したLB液体培地を室温まで冷ます。

**4.** AmpまたはKanのstock（100 mg/mL）を**100 µL**加え、混合する。

**5.** Mini Cultureの残りの大腸菌培養液をフラスコに移し、シェーカーで一晩培養する。

- ウイルス関連プラスミド：**30℃**
- それ以外のプラスミド：**37℃**

> **注意：** Midi Cultureの種に使用したMini Cultureは、Midi Prep終了まで廃棄せず、低温で保管する。
