# ミディプレップ（Midiprep）


## ■ ミディプレップとは

大腸菌から中量のプラスミドDNAを精製する操作である。

## ■ 使用するもの

- NucleoBond Xtra Midi/Maxi（元資料の製品表記：NucleoBand Xtra Midi/Maxi）
- Buffer RES / LYS / NEU / EQU / WASH / ELU
- イソプロパノール、70% EtOH、滅菌水
- 50 mLチューブ、15 mL回収チューブ、カラム、遠心機
- NanoDrop

## ■ 手順

**1.** Midi Culture後の大腸菌培養液を50 mLチューブに移す。

**2.** **5,000 rpm、4℃、10分**遠心する。

**3.** 上清を適切な廃液容器に捨てる。

**4.** **Buffer RESを8 mL**加え、ペレットが見えなくなるまでボルテックスする。Buffer RESへのRNase添加状況を確認する。

**5.** **Buffer LYSを8 mL**加え、転倒混和する（ボルテックス禁止）。室温で**5分**インキュベートする。

**6.** **Buffer NEUを8 mL**加え、全体が青色から白色になるまで転倒混和する。

**7.** カラム内のフィルターに**Buffer EQUを12 mL**加え、湿らせる。

**8.** 溶解液をカラムに流し、流れ切るまで静置する。

**9.** カラムのフィルターに**Buffer EQUを5 mL**加えて洗浄する。

**10.** フィルターを外し、カラム壁に**Buffer WASHを8 mL**加える。

**11.** カラムを回収用15 mLチューブに固定し、**Buffer ELUを5 mL**加えて溶出液を回収する。

**12.** **イソプロパノール3.5 mL**を加え、転倒混和する。

**13.** **10,000 rpm、4℃、30分**遠心する。

**14.** パスツールピペットで上清を除去する。

**15.** **70% EtOHを3 mL**加える。

**16.** **10,000 rpm、4℃、5分**遠心する。

**17.** パスツールピペットとP10ピペットで上清を除去する。

**18.** **10,000 rpm、4℃、1秒**遠心する。

**19.** 残ったEtOHをP200で完全に除去する。

**20.** 蓋を開けて約**10分**放置する。

**21.** 滅菌水を**100 µL**加え、ピペッティングで溶解して1.5 mLチューブに移す。

**22.** NanoDropでDNA濃度を測定し、元資料では**約800 ng/µL**になるように希釈すると記載されている。

> **注意：** 製品の表記と試薬条件は元資料に基づく。キットの現行マニュアルや使用カラムのサイズを優先して確認すること。
