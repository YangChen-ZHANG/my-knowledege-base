# コロニーのピックアップ（Colony Picking）


## ■ 使用するもの

- 滅菌丸底チューブ（スピッツ）
- LB液体培地
- Ampicillin（Amp、100 mg/mL）またはKanamycin（Kan、100 mg/mL）
- 滅菌済みのつまようじ、ピンセット
- シェーカー

## ■ 手順

**1.** 滅菌丸底チューブに**日付・名称・サンプル番号**を記載する。

**2.** 安全キャビネット内で必要量のLB液体培地を取り分け、AmpまたはKanを**1,000倍希釈**で加える（最終濃度**100 µg/mL**）。

**3.** LB液体培地を**2 mLずつ**分注する（Mini culture）。

**4.** 滅菌したつまようじでコロニーを採取し、LB液体培地に入れる（ピンセット先端は必要に応じて滅菌する）。

**5.** シェーカーで一晩（O/N）培養する。

- ウイルス関連プラスミドの増幅：**30℃**
- それ以外のプラスミド：**37℃**（組換え・欠失が起こりやすい）
