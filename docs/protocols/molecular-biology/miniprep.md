# ミニプレップ（Miniprep）


## ■ ミニプレップとは

大腸菌内で増幅したプラスミドDNAを少量精製する操作である。

## ■ 使用するもの

- 大腸菌培養液
- Solution I / II / III
- クロロホルム、イソプロパノール、70% EtOH
- TE・RNase Buffer（氷上）
- 1.5 mLチューブ、遠心機、アスピレーター、ピペット

## ■ 手順

**1.** 大腸菌培養液を1.5 mLチューブにデカントで移す。

**2.** **13,000 rpm、室温、30秒**遠心する。

**3.** 上清を適切な廃液容器に捨てる。

**4.** **Solution Iを100 µL**加え、ペレットが見えなくなるまで混合する。

**5.** **Solution IIを200 µL**加え、転倒混和する。

**6.** **Solution IIIを150 µL**加え、転倒混和する。

**7.** **クロロホルムを10 µL**加え、転倒混和する。

**8.** **13,000 rpm、室温、30秒**遠心する。

**9.** 上清**450 µL**を新しい1.5 mLチューブに移す。

**10.** **イソプロパノール450 µL**を加え、転倒混和する。

**11.** **13,000 rpm、室温、5分**遠心する。

**12.** 上清をアスピレーターで除去する。

**13.** **70% EtOHを1 mL**加える。

**14.** **13,000 rpm、室温、30秒**遠心する。

**15.** 上清をアスピレーターで除去する。

**16.** **13,000 rpm、室温、1秒**遠心する。

**17.** 残ったEtOHをピペットで除去し、ペレットが透明になるまで数分放置する。

**18.** **TE・RNase Bufferを50 µL**加え、混合して溶解する（氷上）。

**19.** **4℃**で保存する。

> **元資料の記載について：** 概要には「カラムを用いて精製」とあるが、実際に列挙された上記の手順は**イソプロパノール沈殿法**である。ここでは手順の記載を優先して転記した。
