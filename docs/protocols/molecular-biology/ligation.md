
# ライゲーション（Ligation）

## ■ Ligationとは

DNA断片同士を連結する操作である。

DNAリガーゼを用いて、切断されたDNAの末端をつなぐ。
InsertをVectorに挿入する遺伝子クローニングで使用される。

## ■ 使用するもの

- Vector
- Insert（Linker産物）
- Ligation high Ver.2（LGK-201）
- 滅菌水
- PCRチューブ

## ■ 手順

### ＜Ligation high Ver.2を用いる場合＞

**1. 必要な溶液をPCRチューブで混合する。**

| 試薬 | 使用量 |
|---|---|
| Vector | 50 ng |
| Insert | Vector : Insert = 1 : 8（モル比） |
| Ligation high Ver.2 | 使用条件に応じて調整 |
| 滅菌水 | Total 10 µLになるように添加 |
| **Total** | **10 µL** |

!!! note "注意事項"
    VectorとInsertの比率は、モル比1:8を
    デフォルトとし、必要に応じて変更する。

**2. 16℃で30分間インキュベートする。**

---

### ＜TOPO Cloningの場合＞

**1. 必要な溶液をPCRチューブで混合する。**

| 試薬 | 使用量 |
|---|---|
| Insert | 2 µL |
| Salt solution | 0.5 µL |
| pCWII-Blunt TOPO | 0.5 µL |
| **Total** | **3 µL** |

**2. 室温で30分間インキュベートする。**

---

### ＜TA Cloningの場合＞

**1. 必要な溶液をPCRチューブで混合する。**

| 試薬 | 使用量 |
|---|---|
| Insert | 2 µL |
| pMD20-T vector | 0.5 µL |
| Ligation Mighty Mix | 2.5 µL |
| **Total** | **5 µL** |

**2. 16℃で30分間インキュベートする。**
