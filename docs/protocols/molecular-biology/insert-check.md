# インサートチェック（Insert Check）


## ■ 使用するもの

- Miniprepで得たプラスミドDNA
- 適切な制限酵素（2種類）
- 10× rCutSmart Bufferまたは10× FD Buffer
- 滅菌水
- アガロース、1× TAE、EtBr
- DNA Ladder、Loading Dye、電気泳動装置

## ■ 手順

**1.** 使用する制限酵素に適したBufferを選び、PCRチューブで以下を混合する。

| 試薬 | 使用量 |
|---|---:|
| プラスミド | 3 µL |
| 制限酵素1 | 0.25 µL |
| 制限酵素2 | 0.25 µL |
| 10× rCutSmart / 10× FD Buffer | 1 µL |
| 滅菌水 | 5.5 µL |
| **合計** | **10 µL** |

反応液の共通成分は、必要に応じて（サンプル数＋1）反応分まとめて調製する。

**2.** **37℃で60分**インキュベートする。

**3.** アガロースゲルを調製する。

- 元資料では、1× TAEは大きいゲルで**40 mL**、小さいゲルで**20 mL**使用する。
- アガロース濃度は**1%**と記載されている。
- EtBrは**1 µL**と記載されている（ゲル容量ごとの調整については記載なし）。
- 電子レンジで溶解させ、気泡を取り除いてゲル型に流し、**30分以上**静置する。

**4.** アガロースゲル電気泳動を行う。

- DNA Ladder：**3 µL**
- Sample：Loading Dyeを最終**1×**になるように加えて全量ロード

> **確認事項：** 元資料のアガロース重量欄は表記が不明瞭なため、数値は転記せず、実際のゲル量と濃度に基づいて確認すること。EtBr等の取り扱いは研究室の安全手順に従う。
