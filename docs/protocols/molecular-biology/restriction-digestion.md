# 制限酵素処理（Restriction Digestion）


## ■ 使用するもの

- プラスミドDNA
- 制限酵素1、制限酵素2
- 10× rCutSmart Buffer
- 滅菌水
- 1.5 mLチューブ

## ■ 手順

**1.** 以下の溶液を1.5 mLチューブで混合する。

| 試薬 | 使用量 |
|---|---:|
| プラスミド | 10 µg（体積は濃度に応じて調整） |
| 制限酵素1 | 2 µL |
| 制限酵素2 | 2 µL |
| 10× rCutSmart Buffer | 4 µL |
| 滅菌水 | 全量40 µLになるように調整 |
| **合計** | **40 µL** |

**2.** 37℃で**4時間**インキュベートする。

> **注意：** 使用する酵素の適合バッファーと反応条件は、実際の組み合わせに応じて確認する。
